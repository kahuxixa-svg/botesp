# Troko on LILYGO T-Display-S3 (without audio)

For the original 1.9-inch T-Display-S3, ESP32-S3R8, 16 MB flash,
8 MB octal PSRAM, ST7789 170x320 LCD with an **8-bit i80 parallel bus**.
Not for the AMOLED, Pro, or classic ESP32 T-Display models.

This is a distinct board family/OTA identity. Existing LILYGO board profiles
are unchanged. The no-audio variant never configures external I2S pins;
microphone, speaker, voice wake-up and push-to-talk are intentionally pending.

## Display and buttons

| Signal | GPIO |
| --- | --- |
| Power enable | 15 (high) |
| Backlight | 38 (active high) |
| RD / WR | 9 (high) / 8 |
| DC / CS / RST | 7 / 6 / 5 |
| D0..D7 | 39, 40, 41, 42, 45, 46, 47, 48 |
| BOOT / second button | 0 / 14 |

Portrait UI: 170x320, USB and buttons at the top, no axis swap, both axes mirrored
for a 180-degree panel rotation, offset (35,0). Every GIF uses zero image rotation;
the panel provides the same orientation for the clock, expressions and scenes.
The pinout follows the manufacturer's
[factory example](https://github.com/Xinyuan-LilyGO/T-Display-S3/tree/main/examples/factory).
The existing `SpiLcdDisplay` LVGL adapter also handles i80 panel IO and performs
the RGB565 byte swap; do not enable a second byte swap on the bus.

- BOOT click: show the pending-audio notice.
- BOOT long press: enter XiaoZhi's Wi-Fi provisioning mode.
- Second button click: cycle 21 original animated Troko expressions offline.
- Second button double click: start a five-second visual timer demo.
- Second button long press: start 25-minute focus, or cancel an active timer.
- Wi-Fi setup, activation code and connection status use the upstream UI.

## Build

Use ESP-IDF `release/v6.1`, with all its submodules and S3 tools installed:

From the containing workspace, `scripts/build.ps1` first verifies and packs the
original GIFs via `scripts/prepare_troko_assets.py`. The custom pack is generated
at `.local/troko-eyes-assets.bin`, relative to that workspace. Then it runs:

```powershell
python scripts/build.py lilygo/troko-t-display-s3 --name troko-lilygo-t-display-s3-no-audio --language es-ES --wake-word disabled
```

Language is a user build option, not part of the board defaults. This variant
explicitly opts out of wake-word detection until the audio hardware is present.

## Original Troko animations

The user's official `troko-firmware-es.zip` contains only compiled firmware and
documentation. Its firmware SHA256 is
`0bc34131e31c2b5d77af7c38281829a955cc10a6e4149d368a0be468cbfdc840`.
Its mmap assets at `0xc00000` contain 21 GIFs. These were extracted unchanged to
`assets/`, with hashes and provenance plus the package license. Speech models
are omitted while audio is paused. No downloaded GIF was recreated or edited.

`TrokoEyesDisplay` uses the existing LVGL GIF player and scales the original
240x240 animations proportionally to fit the screen. It preserves status,
activation, setup and subtitle controls. The compiled Troko application itself
cannot be ported to a different display bus by changing GPIO data in its binary.

Five additional, original idle GIFs live in `assets/idle/`, generated by the
workspace's `scripts/generate_idle_animations.py`. Each is 160x256, 96 frames,
80 ms per frame, looping on a black background: puppy/ball, rocket, aquarium,
juggling, sleeping puppy. They alternate with random original expressions after
12 seconds of inactivity. Manual gestures, notifications, previews and non-idle
application states take priority. Only one GIF decoder runs at a time.
The generated face targets the animated scene objects: downward puppy/ball gaze
and smiling at catches, gold-fish tracking, highest-ball tracking, launch reactions
and progressively sleepy lids. Solid white eyes without pupils use gaze offsets
and curved lower lids to express attention and smiles. In the rocket scene,
only the pilot's eyes appear inside the cabin; there is no second face above it.
All of these
changes are baked into the idle GIFs; the original 21 Troko assets stay unchanged.
The clock remains white on black; idle status icons are hidden to remove the
tiny glyph that can look like a stray white pixel. Low-battery alerts remain.

## Audio follow-up

Do **not** copy the Troko guide's GPIO assignments: its microphone pins 40–42,
amplifier pins 47–48 and volume pin 38 are already used by this integrated LCD.
Choose exposed free GPIOs against the actual board revision before adding
INMP441/MAX98357A. Preserve this no-audio build as a separate variant.

Proposed independent I2S buses on the original board's exposed header:
INMP441 BCLK=1, WS=2, SD=10; MAX98357A BCLK=11, LRC=12, DIN=13.
These pins remain unconfigured. Microphone power is 3V3, L/R=GND, shared GND;
amplifier VIN can use USB 5V. Never connect either differential speaker output
to GND. See the containing workspace README for wiring and manufacturer sources.

`troko_timer.cc` provides one local visual reminder/countdown (1 second to
24 hours) and a 25-minute focus preset. These work offline, have no sound and
are lost on reboot. Timer callbacks schedule UI work on the application task;
cancellation invalidates already queued completion callbacks.

MCP tools: `self.troko.timer.start` (`seconds`, `message`, max 160 bytes),
`self.troko.timer.status`, `self.troko.timer.cancel`, `self.troko.focus.start`.
A second active timer is rejected rather than silently replacing a reminder.

Tavily, Telegram, persistent reminders, time-of-day alarms and the custom
“Troko” wake word remain future application features.
